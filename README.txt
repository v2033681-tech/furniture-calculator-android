Мебельный расчёт — пакет PWA

В архиве находятся файлы веб-приложения. Чтобы обновить существующий сайт Netlify,
нужно развернуть (deploy) именно содержимое папки, а не прикреплять ZIP как файл
к агенту. В корне развертывания должны находиться index.html, manifest.json,
sw.js и icon-*.png.

После публикации открой сайт в Google Chrome Android, обнови страницу и проверь меню
Chrome: должна появиться опция Установить приложение (если Chrome признаёт сайт
устанавливаемым). Не все браузеры Android поддерживают установку PWA одинаково.
